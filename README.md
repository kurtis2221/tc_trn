# True Crime: Streets of LA Trainer
Warning!

Use the trainer for your own risk! The game can easily crash from it!

## Info
Trainer with simple, teleport and NoClip fly cheats.

The hotkey list with D0, D1 and similar means the normal number keys.

## Tools Needed To load the project properly
- Visual C# 2008 Express or newer
